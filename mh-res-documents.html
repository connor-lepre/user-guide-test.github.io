Document FolderReviewed 2018

Upload documents that belong to a referral or case, including paper signatures collected for Applicant Authorization or LTSR Acknowledgement.

On this screen

Upload a document
Add Document → Browse to the file, then set record type, document date, description, and client name, and Save.
Open or edit
Click a file name to open it. After upload, only the document date, description, and client name can be changed.
Do not save documents to personal or public computers. Doing so can violate HIPAA. To delete a document, contact your Application Specialist with the case/referral number and document name.

Share a caseReviewed 2017

Give another MH Residential user view or edit access to all or part of a case.

On this screen

Case sharing
Pick agency/provider, unit, and staff, then grant view or write access per screen (write implies view). Sharing any screen automatically shares Case Summary. Shared cases show on the recipient's dashboard; supervisors can manage sharing for their unit.
Works the same way as Referral Share.
