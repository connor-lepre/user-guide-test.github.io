Find & register a client

Search for the client first. Register a new client only if the search returns no match.

Tool

Last reviewed

Search before you register. Each client has one record in the county’s Master Client Index (MCI). Registering without searching can create a duplicate record and split the client’s history. Register only when the search finds no match.

1

Search for a client

DHS Providers

Searching does not change any records. The results show whether to open an existing client or register a new one.

Steps

  1. Open the client search.Sign in through Okta, open the assessment tile, then go to the CANS / ANSA menu and choose Client > Search.
  2. Set how each field should match.For First and Last Name, pick a match type: Sounds Like, Starts With, or Is. “Sounds Like” returns the most results and is the recommended first search.
  3. Enter what you know.Only Last Name is required. Add Date of Birth, Gender, SSN, or MCI number to narrow the results.
  4. Select Search and read the result.The search returns either a list of matches or a “No Match Found” message, described below.

Search results

Matches

One or more clients are listed

Open a row to check the Info, Address, and Assessment History tabs and confirm it’s the right person. Once confirmed, select the row and choose Show to open that client. No registration is needed.

No match

“No Match Found”

Select OK, then continue to Step 2 · Register a new client below.

Troubleshooting

What to do
No results, but you expect the person to existTry again Change the match type to Sounds Like and search on Last Name only. Spelling differences and nicknames are the most common cause.
Too many results to tell them apartNarrow Add Date of Birth or SSN, then use the Info and Assessment History tabs to confirm.
Opened the wrong client with ShowRecoverable Selecting Show does not change any records. Return to Client > Search and search again.
Only if the search finds no one
2

Register a new client

DHS Providers

Start here only after a search returns “No Match Found.” The New button is not available until a search has run.

The Verify Individual step compares your entry against existing MCI records. This identifies a person recorded under a slightly different spelling before a duplicate is created.

Steps

  1. Select New.From the search screen, after “No Match Found,” choose New to open a blank client record.
  2. Enter the core identifiers.First Name, Last Name, SSN, Date of Birth, and Gender.
  3. Select Verify Individual.This checks your entry against the Master Client Index.
  4. Handle the match result.If MCI returns a possible match of 95% or higher, you must select the existing person rather than create a new record. If you’re certain it’s a different person, the Service Desk can override. If there’s no match, continue.
  5. Complete the demographics.Add Race and Ethnicity to finish the person’s profile.
  6. Add an address.Choose New (or Edit), enter the address, and validate against Postal. If it won’t validate but you know it’s correct, use Save Without Verification.
  7. Select Save.The client is registered and ready to assess.

Troubleshooting

What to do
Verify Individual returns a 95%+ match but you believe it’s a different personCheck first Open the match and compare DOB and SSN. If it is a different person, contact the Service Desk for an override instead of creating a duplicate record.
You registered someone who turned out to already existRecoverable Call the Service Desk (412-350-4357) to merge or correct the records.
The address won’t validate against PostalOption If the address is correct, use Save Without Verification instead of changing it.
The New button is greyed outExpected Run a search first. The New button becomes available after a search has run.
